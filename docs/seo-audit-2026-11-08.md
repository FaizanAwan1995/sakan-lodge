## Changes justified by the evidence and source review

1. Give the suburb pages distinct descriptions, visible household context, rent/stay details and direct location-prefilled enquiry links. Start with existing URLs already receiving search impressions.
2. Make the student title specific to student rooms and the shared-room starting rate; direct its enquiry links to the existing form.
3. Prioritise the popular women's page: use a location-specific H1 while preserving the explicit household-transition notice. Give segment enquiry controls native links as well as JavaScript behaviour.
4. Correct “without excess utility charges” copy to reflect the Fulham electricity allowance already present in agreements and other website sections.
5. Remove a duplicate WebSite structured-data entity and conflicting index/noindex robots declarations on the enquiry document.
6. Consolidate privacy, terms and enquiry URL variants. Route the root staff index to `/ledger/`.
7. Remove the global SPA asset fallback. The Worker already serves the Ledger shell explicitly. Missing public assets should return 404 rather than an indexable staff shell.

No ranking or traffic improvement is claimed at deployment. Compare subsequent Search Console periods after recrawling; the current search sample is too small for confident CTR or keyword conclusions. No paid-ad budget or campaign was changed.
